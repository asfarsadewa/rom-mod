# Security

## Scope

- rom-mod runs a local HTTP server on the loopback interface and writes files chosen by the user.
- Reports are welcome for issues that let a remote page or a crafted input file read, write or execute anything the user did not request.

## Reporting

- Use GitHub private vulnerability reporting on this repository.
- Include the version, the platform, and a minimal reproduction.
- Do not open public issues for undisclosed vulnerabilities.

## Supported versions

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |
